# [대화 프로파일러] 신규 '관계 유형' 4종 확장 및 드롭다운 고도화 계획

사용자가 대화 상대와의 역학을 더욱 세밀하게 분석할 수 있도록, 가장 수요가 높은 4가지 신규 관계 유형을 추가하고 인터랙티브 드롭다운 및 AI 분석 프롬프트를 확장합니다.

## User Review & Critical Decisions

> [!IMPORTANT]
> 사용자와의 인터뷰(Q&A)를 통해 확정된 사항을 기반으로 구현을 진행합니다.

- **확정된 신규 관계 유형 (4종)**:
  1. **전연인·재회** (💔): 이별 후 연락 의도, 미련, 후폭풍 및 감정선 해독
  2. **가족·친척** (🏡): 잔소리 속 숨겨진 애정, 츤데레 표현, 세대 차이 맥락 분석
  3. **소개팅·애프터** (☕): 첫만남 후 애프터 호감도, 다음 만남 의사, 그린라이트 신호 감지
  4. **중고거래·협상** (📦): 당근/번개 거래 매너, 네고(가격 흥정) 의도, 쿨거래 vs 파기 낌새 탐지
- **UI 배치 방식**: 카테고리 분리 대신, 사용자가 한눈에 직관적으로 비교·선택할 수 있도록 2열 그리드 드롭다운에 총 8개 유형을 균형 있게 배치

---

### 1. Overview & Core Concept

- **목적**: 대화 심리 프로파일링의 맥락(Context)을 구체화하여, 메신저 스크린샷 분석 결과의 신뢰도와 추천 답장의 적중률을 극대화
- **사용자 경험**:
  - 기존 4종(`연애·썸`, `직장·업무`, `친구·지인`, `일상·기타`)에서 8종으로 확장
  - 드롭다운 트리거를 누르면 8개의 카드형 버튼이 이모지와 전용 색상 테마로 깔끔하게 노출
  - 선택 시 상단 인풋에 실시간 반영되며 드롭다운이 자동으로 닫힘

---

### 2. User Experience & Visual Design

- **8개 관계 유형 테마 매핑**:
  - `연애·썸` (💘 보라 계열): 호감도 및 설렘 지수
  - `소개팅·애프터` (☕ 핑크 계열): 첫인상과 애프터 호감도
  - `전연인·재회` (💔 로즈/레드 계열): 미련 및 연락 심리 해독
  - `직장·업무` (💼 블루 계열): 업무 뉘앙스와 예의선
  - `친구·지인` (🤝 청록 계열): 친밀도 및 유대감 체크
  - `가족·친척` (🏡 오렌지 계열): 세대 차이와 숨은 애정
  - `중고거래·협상` (📦 올리브/라임 계열): 매너와 네고 의도 파악
  - `일상·기타` (💬 앰버/스톤 계열): 신뢰도 및 일반 의도
- **인터랙션 및 컴포넌트 구조**:
  - 드롭다운 패널 최대 높이 지정 및 부드러운 스크롤(`max-h-[360px] overflow-y-auto`)
  - 바깥 영역 터치 및 '닫기' 버튼 지원
  - 선택된 아이템의 시각적 활성화 표시(우측 체크 도트 및 전용 테두리 강조)

---

### 3. Key Product Decisions & Trade-Offs

- **결정 1: 관계 유형 8종 직렬 그리드 노출**:
  - *선택 이유*: 탭이나 복잡한 아코디언보다 2x4 그리드 형태가 모바일 한 손 터치 및 빠른 탐색에 가장 직관적임
- **결정 2: 서버 및 Gemini AI 프롬프트 특화**:
  - *선택 이유*: 전연인/가족/소개팅/중고거래는 해석의 결이 완전히 다르므로, 관계 유형에 따라 분석 관점(예: 중고거래는 호감도가 아닌 '신뢰도/거래 매너 점수')을 프롬프트에 반영
- **결정 3: 오프라인/Fallback 로직 동기화**:
  - *선택 이유*: 네트워크 장애나 일시적 API 지연 상황에서도 신규 4개 유형에 부합하는 정교한 심리 분석 결과와 추천 답장이 반환되도록 백엔드 보강

### 4. Technical Architecture & Data Strategy

```
┌─────────────────────────────────────────────────────────────┐
│                    Client UI (src/App.tsx)                  │
│                                                             │
│  [드롭다운 트리거] ──> 클릭 ──> [8종 관계 유형 2열 그리드]     │
│   (선택된 상태 유지)             (아이콘 + 한줄 설명)         │
│                                                             │
│       │ Base64 Screenshot + RelationshipType ('전연인·재회' 등)
│       ▼                                                     │
│  [POST /api/decode] ────────────────────────────────────┐   │
└─────────────────────────────────────────────────────────┼───┘
                                                          ▼
┌─────────────────────────────────────────────────────────────┐
│                   Server (server.ts)                        │
│                                                             │
│  ┌─────────────────────────┐   ┌─────────────────────────┐  │
│  │   Gemini 3.1 Vision     │   │   Contextual Fallback   │  │
│  │   8종 관계별 프롬프트 주입 │   │   8종별 맞춤형 시뮬레이션 │  │
│  └─────────────────────────┘   └─────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

- **타입 정의 (`src/types.ts`)**:
  - `RelationshipType` 유니온 타입에 `'전연인·재회' | '가족·친척' | '소개팅·애프터' | '중고거래·협상'` 추가
- **프론트엔드 (`src/App.tsx`)**:
  - `RELATIONSHIP_OPTIONS` 배열에 4개 항목(이모지, 타이틀, 설명, 테마 컬러) 추가
  - 드롭다운 레이아웃 스크롤 및 모바일 뷰 최적화
- **백엔드 (`server.ts`)**:
  - `generateContextualResult` 함수에 신규 4개 유형 전용 분석 결과 및 맞춤 답장 프리셋 추가
  - Gemini 비전 분석 프롬프트에 신규 관계 맥락 가이드 보강
